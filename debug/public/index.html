serial-broker · debugging surface

Every setting and every piece of status the library has. This tab uses the library the way an application does. The origin shows what every tab is doing, through the diagnostics observer, which takes no part in ownership: looking never moves a port. The page sets nothing up on its own.

The library could not start in this browser. Web Serial needs Chrome, Edge or Opera, in a secure context: HTTPS, or localhost. The platform panel says what is missing.
